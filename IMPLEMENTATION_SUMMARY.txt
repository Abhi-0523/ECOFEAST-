🚀 TO RUN THE APPLICATION - FOLLOW THESE STEPS
════════════════════════════════════════════════════════════════════════════

⚠️  IMPORTANT: Your system is missing required software:
   ❌ MySQL Server (database)
   ❌ Apache Tomcat 9+ (web server)
   ❌ Maven 3.8+ (build tool)

STEP 1️⃣  INSTALL REQUIRED SOFTWARE (15 minutes)
────────────────────────────────────────────────────────────────────────────

Option A - Run Setup Script (Recommended):
   PowerShell: . .\SETUP.ps1
   Or manually:

Option B - Manual Installation:

MySQL Database:
   1. Go to: https://dev.mysql.com/downloads/mysql/
   2. Download: MySQL 8.0 Community Server (Windows)
   3. Run installer
   4. Remember your password
   5. Add MySQL\bin to system PATH

Apache Tomcat 9:
   1. Go to: https://tomcat.apache.org/download-90.cgi
   2. Download: apache-tomcat-9.x.x-windows-x64.zip
   3. Extract to: C:\tomcat
   4. Set environment variable: CATALINA_HOME = C:\tomcat

Maven 3.8+:
   1. Go to: https://maven.apache.org/download.cgi
   2. Download: apache-maven-3.8.x-bin.zip
   3. Extract to: C:\maven
   4. Set environment variable: M2_HOME = C:\maven
   5. Add to PATH: C:\maven\bin

Environment Variables:
   Windows Key + X → System → Advanced system settings → Environment Variables
   Add/Update:
   • JAVA_HOME = C:\Program Files\Java\jdk-17.x (or your JDK path)
   • CATALINA_HOME = C:\tomcat
   • M2_HOME = C:\maven
   • Add to PATH: %JAVA_HOME%\bin, %CATALINA_HOME%\bin, %M2_HOME%\bin
   
   ⚠️  RESTART PowerShell/Command Prompt after setting variables!

STEP 2️⃣  CREATE DATABASE
────────────────────────────────────────────────────────────────────────────

Run in PowerShell/Command Prompt:

   mysql -u root -p < database/schema.sql

   (Enter your MySQL root password when prompted)

Verify database created:
   mysql -u root -p
   source database/schema.sql;
   USE ecofeast;
   SHOW TABLES;
   exit;

STEP 3️⃣  BUILD THE PROJECT
────────────────────────────────────────────────────────────────────────────

Run in PowerShell (in EcoFeast directory):

   mvn clean package

Expected output:
   [INFO] BUILD SUCCESS
   [INFO] Created: target/ecofeast.war

STEP 4️⃣  DEPLOY TO TOMCAT
────────────────────────────────────────────────────────────────────────────

Copy WAR file to Tomcat:

   Copy-Item target/ecofeast.war $env:CATALINA_HOME/webapps/

Or manually: Copy target/ecofeast.war to C:\tomcat\webapps\

STEP 5️⃣  START TOMCAT AND ACCESS APPLICATION
────────────────────────────────────────────────────────────────────────────

Start Tomcat:
   PowerShell: & $env:CATALINA_HOME/bin/startup.bat
   Or double-click: C:\tomcat\bin\startup.bat

Wait for message: "Tomcat started successfully"

Open in browser:
   http://localhost:8080/ecofeast/

⚠️  TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

❌ "mvn command not found"
→ Maven not installed or PATH not updated
→ Solution: See QUICKSTART.md or run SETUP.ps1

❌ "MySQL connection refused"
→ MySQL server not running
→ Solution: Start MySQL service
   PowerShell: net start MySQL80  (or your MySQL service)

❌ "Tomcat won't start"
→ Port 8080 already in use
→ Solution: Check: netstat -ano | findstr :8080
   Kill process: taskkill /PID [PID] /F

❌ "Database not found"
→ Schema not imported
→ Solution: Run: mysql -u root -p < database/schema.sql

❌ "403 Forbidden error"
→ RBAC filter denying access
→ Solution: Check user role matches URL
   /admin/* → requires ADMIN role
   /user/* → requires USER role
